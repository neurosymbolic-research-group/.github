## About us

The **Neurosymbolic Research Group (NRG)** is part of the [Machine Learning Laboratory](https://ml.cs.put.poznan.pl/en) at the Institute of Computing Science, [Poznan University of Technology](https://www.put.poznan.pl/), Poland.
We conduct basic and applied research on machine learning architectures, algorithms and applications that combine mainstream deep learning with symbolic reasoning and representations.

## Research areas

- **Neurosymbolic architectures** — models that integrate neural learning with symbolic structure
- **ML for structured data** — knowledge graphs, ontologies, event logs, and language
- **[Process mining](https://processm.cs.put.poznan.pl)**
- **Mathematical programming model mining**
- **AI for symbolic reasoning** about properties of systems
- **Program synthesis** with heuristic and exact algorithms
- **Evolutionary computation** and other metaheuristics
- **Medical applications** of machine learning
